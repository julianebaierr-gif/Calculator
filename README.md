# 🧮 CalcHub — High-Precision Online Calculators Suite

A production-grade suite of **400+ specialized, high-precision web calculators** engineered according to published international mathematical, clinical (WHO), financial, and industrial engineering standards (IEC 60364 & NEC NFPA 70).

---

## 🌟 Key Features

* **100% Light Theme Design:** Clean, modern, high-contrast aesthetic crafted for long-session readability and professional trust. Pure white, soft slate, and electric indigo typography.
* **Instant Client-Side Computation:** Zero server lag, 100% private, zero user registration, and sub-millisecond execution updates.
* **Structured Semantic Data:** High-priority citation definition boxes (`.geo-citation-box`) formatted for instant answer discovery.
* **Level 1–6 Technical SEO:**
  * Clean semantic static URLs with automated extension stripping via `vercel.json`.
  * Advanced JSON-LD Schema on every page: `WebApplication`, `MathSolver`, `FAQPage`, `BreadcrumbList`, and `Organization`.
  * Interactive Table of Contents (TOC) generating Google Mini Sitelinks.
  * Self-referencing canonical structure pointing to `https://calchub.org/`.
  * `robots.txt` blocking duplicate parameter queries (`/?s=*`, `/?q=*`).
  * Dynamic `sitemap.xml` covering all clean production URLs.

---

## 🚀 Deployment

The project is configured for seamless deployment on Vercel with clean URLs and optimized caching headers defined in `vercel.json`.
